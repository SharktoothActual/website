# Obligatory post after 1 month

Well it's been a while and I'm back on my bullshit again. Only difference is I'm motivated to write, not complain.
My last post just kinda felt like a rant where I made a stupid point with bad examples (at least, to me).
Really I was just bothered at people dragging politics into Linux.
Of course, politics poisons everything and all that, but for me it's the lack of care in that somehow Linux has become a debate battleground.

I used Hyprland and GNOME in particular because I see them pulling this kind of shit.
It's no secret that DHH (creator of Hyprland) hates some people, and it's no secret that the GNOME foundation hates anyone who doesn't hold all of their opinions.
You can think one is right and the other is wrong all you want, but you can't deny they're both assholes.

So my post was meant to ask "Why does anyone need to be an asshole at all?"
And of course, nobody responded because nobody other than web crawlers actually reads this. And that's fine.
I've done my own introspection and I think the notion that being an asshole is optional still stands.
These two communities are not at war with each other, not directly.
But their differing ideologies and their individual participation across projects can pose problems.
And it benefits absolutely nobody other than their own egos. Which brings me to my point: There's too much ego-stroking going on.

I'd like to call attention to a *better* example that has come up. And it's one that's predominantly non-political, to boot.
Somewhat recently, an administrator or maintainer for the Artix linux project left the team after giving an opinion on display servers.
The admin stated to a user that he would recommend Xorg over XLibre because XLibre was having code quality issues that translated to instability.
It was a very matter-of-fact statement and a direct answer to a direct question.
Well, one of the XLibre maintainers saw that and threw a conniption fit about it that resulted in brigading the forum using Tor and bogus accounts.
Long story short, admin leaves the project entirely because his name got dragged through the mud because someone got upset.
The ironic part is, if the code hadn't been dogshit then the admin wouldn't have said this.
The very person who wrote the crappy code is the same person villainizing this admin. It's truly mystical.

It really is all about ego. The XLibre guy decided to take a response he didn't like personally, drag that admin's name through the mud, now Artix suffers for it.
Is Artix in dire straits now? No, thankfully; The project is run by great people who know what they're doing.
But it's a blow to the community considering the admin was well liked.
And now (for reasons that should be very obvious at this point), XLibre is no longer the default display manager of Artix.
So everyone loses. All because of one petty individual's egotistical crash-out.

This is far from the only time this has happened in Linux's history and it won't be the last, I'm sure.
But right now is when it *actually matters* because Linux is getting pushed to the masses.
Linux is rapidly approaching the point where it's about to hit 10% market share, for the first time ever.
And as it stands, things are still rather volatile. With so many people looking in, that volatility will hinder growth.

So in conclusion, suck it up and get along. Put the user first.
Make cool shit that others can enjoy, stop trying to be the protaganist.
If someone doesn't like something about your project, listen to them.
If it doesn't match your intentions for the project, apologize for it and move on.
Let them fork it if they want. And if they do, be proactive and lend them a hand if you can.
It's all one big group project, so just try and get along so we can all benefit.
